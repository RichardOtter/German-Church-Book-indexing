
The goal of this GitHub repo is to make publicly accessible my work on indexing and transcription
of German Church Books. See ReadMe.md for more info.


Contributions are encouraged, including:

- Transcription corrections
- Additional indexes
- Place-name identification
- Handwriting interpretation
- Translation assistance
- Documentation improvements
- Automation and tooling

As this data collection is not aimed at seasoned software developers,
the usual GitHub mechanism of contribution by Pull Request may not be helpful- although Pull
Requests will be be appreciated.

Please open an issue or pull request if you find errors, can identify uncertain readings, or would like to add material.
Just include the file name that you think should be changed and the old and new text.
We may have a short discussions about it.

Each update can be suggested by creating a new "Issue".


I am also open to receiving updated files by email  when the contributor is unfamiliar with Git procedures.

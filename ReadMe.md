# German Church Book Indexing and Transcription Project

## Purpose

The primary purpose of this project is to document and preserve my family's genealogical records found in historical German church books (*Kirchenbücher*). Over time, this has grown into a broader effort to create searchable transcriptions and indexes that may be useful to other researchers whose ancestors appear in the same records.

This repository is open source so that others can:

- Reuse the transcriptions and indexes.
- Verify and improve existing work.
- Contribute additional transcriptions.
- Share corrections and interpretations.
- Collaborate with others researching families from the same regions.

If you are working on a similar project, I would be very interested in hearing from you.

## Project Scope

The geographical focus is on the Lower Franconia region of Bavaria, Germany (Unterfranken, Bayern, Deutschland).

The records currently consist of:

- Baptismal registers (*Taufen*)
- Marriage registers (*Ehen*)
- Burial or death registers (*Beerdigungen*, *Sterbefälle*, or *Tote*)

Most source images originate from church books available through the archive or Matriculw-online.eu

## Repository Structure

Each church-book image is accompanied by a corresponding text file containing transcriptions, indexing information, notes, or both.
Most recent efforts don't include an image, but instead provide a URL to the online repository.

Typically, a single image contains two facing pages from the original church book.

Examples:

```text
03686-02-05.png
03686-02-05.txt

05303-03-12 info.txt
05303-03-12.png
```

The text file and image file share the same base filename.

## File Naming

Current filenames follow the naming convention inherited from the Matricula image collection and, ultimately, from the original microfiche numbering system.

## Transcription Philosophy

The goal is to balance historical accuracy with practical usability.

General principles:

- Preserve original spellings whenever possible.
- Record uncertain readings explicitly.
- Avoid silently modernizing names or places.
- Document editorial assumptions in notes.
- Allow future contributors to revisit questionable readings.

The transcription section is accompanied by a translation section which should 
record the data in modern language.

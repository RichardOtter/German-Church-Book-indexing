---

## Rules for Latinizing German Names in Catholic Records

### **Male Names — Endings**

| Latin Ending | Rule / Origin | Example German → Latin |
|---|---|---|
| **-us** | Most common — added to Germanic stem | Konrad → Conradus, Eberhard → Eberhardus |
| **-ius** | For names ending in a vowel or -i- stem | Karl → Carolius *(rare)*, Georg → Georgius |
| **-es** | Greek-origin names | Diogenes-type names |
| **-is** | Some names with soft endings | — |
| **ius** | Names already ending in -i | — |

The **overwhelming rule for male names** is simply:

> **Drop or adapt the ending → add -us**

Examples you can apply yourself:
- Gerhard → **Gerhardus**
- Burkhard → **Burchardus**
- Walther → **Waltherus**
- Dieter → **Dietherus**
- Günther → **Guntherus**
- Rainer → **Reinhardus** / **Rainerus**
- Werner → **Wernerus**
- Siegfried → **Sigifredus**
- Berthold → **Bertholdus**
- Manfred → **Manfredus**

---

### **Female Names — Endings**

| Latin Ending | Rule | Example German → Latin |
|---|---|---|
| **-a** | Most common female ending | Hildegard → **Hildegardis** / **Hildegarda** |
| **-is** | Genitive/declined form, common in older records | Gertrud → **Gertrudis**, Kunigund → **Kunigundis** |
| **-ina** | Diminutive or softened form | Grete → **Gretina** *(rare)* |

The **overwhelming rule for female names** is:

> **Adapt the stem → add -a or -is**

Examples:
- Hildegard → **Hildegardis**
- Mechthild → **Mechtildis**
- Adelheid → **Adelheida** / **Adelaidis**
- Gisela → **Gisela** *(unchanged, already ends in -a)*
- Hedwig → **Hedwigis**
- Irmgard → **Irmgardis**
- Brunhild → **Brunhildis**
- Walburga → **Walburgis**

---

### **Consonant & Spelling Adaptations**

Latin had no **W**, **Z**, or **K** — so these were substituted:

| German | Latin substitute | Example |
|---|---|---|
| **W** | **V** or **Gu-** | Walther → **Valtherus**, Wilhelm → **Guilhelmus** |
| **K** | **C** | Karl → **Carolus**, Konrad → **Conradus**, Klaus → **Nicolaus** |
| **Z** | **S** or **Ts** | — |
| **ü / u-umlaut** | **u** or **ü → i** | Günther → **Guntherus** |
| **ä** | **a** or **ae** | — |
| **ö** | **o** | — |
| **sch** | **sc** or **sch** kept | — |
| **th** | **th** kept or → **t** | Dietrich → **Theodericus** |
| **ck** | **cc** or **c** | — |
| **f** (in some positions) | **ph** | — |

---

### **The Core Formula**

| Gender | Formula |
|---|---|
| Male | *[Germanicized stem]* + **-us** |
| Female | *[Germanicized stem]* + **-a** or **-is** |

So for any unknown name a researcher encounters, applying these rules will usually reveal the German original — or allow you to reconstruct the Latin form of an unlisted German name.
